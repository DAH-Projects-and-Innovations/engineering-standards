# Security policy

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request for a security vulnerability.**

Report it privately with GitHub private vulnerability reporting:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and its possible impact.

Direct link: <https://github.com/DAH-Projects-and-Innovations/TODO-repository/security/advisories/new>

If you cannot use GitHub, write to **TODO: security contact e-mail address**.

## What happens next

- We acknowledge your report within **5 working days**.
- We investigate, keep you informed, and agree with you on a disclosure date.
- We fix the problem, publish a security advisory and credit you, unless you prefer to stay anonymous.

DAH Labs is run mostly by volunteers. We do not have a bug bounty program, but we are grateful for every report.

## Scope

In scope: the code of this repository and its official container images.

Out of scope: vulnerabilities in third-party services (language model providers, hosting), unless our code uses them in an unsafe way.

## If you find a secret

If you find an API key, a token or a password in this repository or its history, report it the same way. Do not use it.
