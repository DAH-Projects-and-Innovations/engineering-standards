# Changelog

All notable changes to the DAH Labs engineering standards are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the standards use [Semantic Versioning](https://semver.org/spec/v2.0.0.html). From the first release, this file is generated by release-please.

## [Unreleased]

### Added

- Foundation standards: Git branching, commits, pull requests, code review, Python, JavaScript and TypeScript, repository structure, required files, Git hooks, CI/CD, security and GitHub settings.
- Compliance levels and a rules matrix generated from the standards pages.
- Getting started pages, including a French page, and a glossary.
- Migration playbook, audit checklist, default branch migration guide and a read-only audit script.
- Templates for Python and front-end projects, pre-commit, GitHub files, community health files and CITATION.cff.
- Reusable workflows: `python-ci.yml`, `node-ci.yml`, `pr-conventions.yml`, `pre-commit.yml` and `security.yml`, tested on fixtures.
- The `dah-branch-name` pre-commit hook.
- Architecture Decision Records 0001 to 0007 and 0009.
